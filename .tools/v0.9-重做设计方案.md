# 万界如林 v0.9 重做设计方案

> 分支：`v0.9-dev`　基线：`8b0ec8c`（v0.8.3 archive）　日期：2026-01
> 本方案彻底推翻旧「点线面」三流派数值设计，以「作祟」为唯一枢纽，鬼气为第二资源（星辉式）。

## 一、核心机制（用户大纲定稿）

### 1. 角色
- 名：万界如林　血量 70　金币 99
- 背景："林"的身份一直是一个谜。

### 2. 鬼气（第二资源，星辉式）
- 起始 1，软上限 20，硬上限 99，战斗内跨回合保留、换战斗重置回 1。
- **鬼墨**（初始遗物）：每场战斗开始 +1 鬼气。
- **金丝鬼墨**（先古升级遗物）：每场战斗开始 +2 鬼气。
- 鬼气 = 第二能量，大量卡牌直接设鬼气费用；同时有卡牌主动产鬼气（花能量/消耗）。
- 视觉：墨黑底 + 幽紫高光 `Color(0.66f,0.45f,0.95f)`。

### 3. 作祟（唯一枢纽，初始技能牌）
- 0 费，X 鬼气，[消耗]。
- 效果：接下来 X 张牌获得强化（升级后 X+1 张），按被影响牌的能量费分层：
  - **0–1 费**：打出时 +1 能量（点）
  - **2 费**：打出时 +1 力量 +1 敏捷 + 抽 2 张（线）
  - **3 费**：打出时把一张 0 费复制（附[消耗]）放入弃牌堆（面）
- 旧点/线/面独立能力牌与机制全部废弃，仅作祟的三个档位保留「点线面」的名字。

### 4. 初始牌组
- 打击 ×4、防御 ×4、作祟 ×2（打击/防御为基本牌，作祟为角色专属初始技能）。

## 二、反无限铁律（设计逐条对照）

- R1：0 费牌不产能量/鬼气。
- R2：鬼气→能量汇率 ≥3:1，且该牌必须[消耗]。
- R3：鬼气→抽牌，不产能量。
- R4：抽 ≥2 张必 ≥1 费或[消耗]。
- R5：触发式收益标每回合上限。
- R6：产鬼气须花能量或[消耗]。
- R7：单卡不同时抽牌+产能量。
- R8：本回合增幅不产可循环资源。

## 三、卡池结构（90 张）

| 档位 | 数量 | 说明 |
|------|------|------|
| 初始（Basic） | 3 | 打击、防御、作祟 |
| 普通（Common） | 20 | 基础伤害/格挡/鬼气经济 |
| 罕见（Uncommon） | 37 | 作祟交互、能力牌、鬼气消耗 |
| 稀有（Rare） | 26 | 核心能力、强力鬼气消耗、终结技 |
| 先古（Ancient） | 4 | 先古之民升级事件奖励 |

> 合计 90 张（Basic 3 + Common 20 + Uncommon 37 + Rare 26 + Ancient 4 = 90）。

## 四、设计骨架（三大建议落地）

1. **鬼气的补充手段**：一批「花能量产鬼气」的能力牌与技能牌（如「聚气」「墨涌」）。
2. **鬼气的消耗手段**：大量卡牌设鬼气费用作为第二能量；X 鬼气费用牌；鬼气→能量/伤害/格挡的转换牌（遵守 R2/R3/R6）。
3. **用能力牌加强点线面（作祟档位）**：
   - 点档（0–1 费）：+能量 → 能力牌让「作祟影响张数+X」或「作祟+能量档位强化」。
   - 线档（2 费）：+力敏+抽 2 → 能力牌让「作祟 2 费档额外+格挡」或「抽牌+1」。
   - 面档（3 费）：0 费复制 → 能力牌让「复制附[消耗]的牌打出后回手」或「复制多 1 张」。

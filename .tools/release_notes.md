# 万界如林 v0.1.1

《杀戮尖塔 2》自定义角色 Mod —— **万界如林**（玩家昵称「林」）。

完整源码与逐轮开发记录见仓库：[jiecheng258/WanJieRuLin](https://github.com/jiecheng258/WanJieRuLin)

## 下载

| 文件 | 说明 |
|---|---|
| `WanJieRuLin-v0.1.1-install.zip` | **安装包**。解压后把 `WanJieRuLin` 文件夹放进游戏 `mods/` 目录即可 |
| `WanJieRuLin-v0.1.1-source.zip` | **源码包**。含全部 C# 源码、本地化、美术资源与构建脚本 |

## 安装

1. 确保已安装 **RitsuLib 0.6.2**（放在 `mods/STS2-RitsuLib/`）
2. 把 `WanJieRuLin` 文件夹解压到：
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\
   ```
3. 启动游戏，接受「已加载 Mod」提示，即可在角色选择界面看到 **万界如林**

> ⚠️ 更新 Mod 后**必须完全退出游戏进程再重开**。RitsuLib 只在游戏启动时加载 DLL，
> 进程还活着就永远是旧代码在内存里。

## 角色概览

| 项目 | 数值 |
|---|---|
| 血量 | 70 |
| 初始金币 | 99 |
| 初始遗物 | 鬼墨 |
| 初始牌组 | 打击 ×4、防御 ×4、绘 ×2 |

**鬼气**：独立于能量的第二资源，机制类似原版星辉。部分卡牌需「耗费鬼气」才能打出；
战斗内跨回合保留，进入下一场战斗时重置为 1 点。

## 本版更新（v0.1.1）

### 修复

- **先古之民「墨染江山」选项彻底修复**（两层问题）
  - 造牌改走官方入口 `RunState.CreateCard()` —— 旧写法手工克隆导致牌未登记进 `RunState`，
    触发 `InvalidOperationException: ... must be added to a RunState before adding it to your deck.`
  - 选项回调补上调「推进事件」的 API `AncientEventModel.StartPreFinished()` ——
    旧写法不推进事件，导致界面停在「选项还在、按钮不可用」的软锁状态
  - 全程用 `try/finally` 兜底：即使加牌失败也会推进事件，不会再次软锁
- 同类造牌写法一并修正：`隐森`（战斗内造衍生物）、`被雷矛`（遗物造牌）

### 平衡（只加强，不削弱）

| 卡牌 | 改动 |
|---|---|
| 持续侵扰 | 伤害 10 → **14**（升级 14 → **18**） |
| 声闻自 | 伤害 6 → **10** |

### 文案纠正

- **打击**：卡面原先写着「获得 1 点鬼气」，但代码里从来没有这个逻辑。
  已把描述与代码同步，改为只显示「造成 {Damage} 点伤害」

## 环境要求

- 游戏版本 **v0.111.0**（Godot 4.5.1 Mono）
- 依赖 **RitsuLib 0.6.2** 或更高

## 已知限制

- 部分卡图使用程序化生成的占位图
- 先古之民复用原版（Neow / Darv）的对话与选项，未制作独立 NPC
- 仅支持单人模式，多人联机同步未验证

# 万界如林 v0.4.6

《杀戮尖塔 2》自定义角色 Mod —— **万界如林**（玩家昵称「林」）。

完整源码与逐轮开发记录见仓库：[jiecheng258/WanJieRuLin](https://github.com/jiecheng258/WanJieRuLin)

## 下载

| 文件 | 说明 |
|---|---|
| `WanJieRuLin-v0.4.6-install.zip` | **安装包**。解压后把 `WanJieRuLin` 文件夹放进游戏 `mods/` 目录即可 |
| `WanJieRuLin-v0.4.6-source.zip` | **源码包**(默认不生成,设 `WJRL_SOURCE_ZIP=1` 可重新生成)。含全部 C# 源码、本地化、美术资源与构建脚本 |

## 安装

1. 确保已安装 **RitsuLib 0.6.2**（放在 `mods/STS2-RitsuLib/`）
2. 把 `WanJieRuLin` 文件夹解压到：

   ```
   C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\
   ```

3. 启动游戏，接受「已加载 Mod」提示，即可在角色选择界面看到 **万界如林**

> ⚠️ 更新 Mod 后**必须完全退出游戏进程再重开**。RitsuLib 只在游戏启动时加载 DLL，
> 进程还活着就永远是旧代码在内存里。

## 角色概览

| 项目 | 数值 |
|---|---|
| 血量 | 70 |
| 初始金币 | 99 |
| 初始遗物 | 鬼墨 |
| 初始牌组 | 打击 ×4、防御 ×4、绘 ×2 |

**鬼气**：独立于能量的第二资源，机制类似原版星辉。部分卡牌需「耗费鬼气」才能打出；
战斗内跨回合保留，进入下一场战斗时重置为 1 点。

## 本版更新（v0.4.6）

### 修复

1. **`TianQiPower.Amount` 隐藏 `PowerModel.Amount` 字段**
   - 编译器报 `CS0108` 警告;玩家获得「相位天气」后,能力卡片角标层数永远显示 `0`(功能本身正常)
   - 反射确认 `PowerModel.Amount` 是 `Int32`、getter/setter 都是 `non-virtual`,
     框架渲染层数时读基类,自定义的 `Amount = 5` 写不进基类 backing field
   - 改名为 `PhaseAmount`,同步 CanonicalVars / OnPlay / 中英文案 / `gen_loc.py`

2. **`WanJieRuLinCardPool.SkillCardTypes` 注册错**
   - 加 `YanMoInk`(研墨,Common Skill):贝雷帽等"随机取技能牌"应能取到它
   - 删 `XiaoHuo`(消火,Attack 卡):不应出现在"技能牌"列表

3. **`audit_placeholders.py` 白名单**
   - 加 `'WanJieV04Powers'`:`WanJieV04Powers.cs` 是 v0.4 引入的"多类一文件",
     脚本按文件名查键的判定需要把它加入 `NON_POWER_FILES` 白名单

### 验证

- `dotnet build`:1 个 CS0108 警告 → **0 警告 0 错误**
- 5 项审计全绿(`hazards` / `placeholders` / `ghostqi` / `infinite` / `综合`)
- 反无限审计自检:坏例子全部命中,干净例子全部放行

### 兼容性

**不影响存档**。卡池规模与 v0.4.5 完全一致(89 张 / 35 个能力 / 5 个遗物)。

### 注意事项

更新 Mod 后**必须完全退出游戏进程再重开**(RitsuLib 只在启动时加载 DLL)。

## 环境要求

- 游戏版本 **v0.111.0**(Godot 4.5.1 Mono)
- 依赖 **RitsuLib 0.6.2** 或更高

## 已知限制

- 部分卡图使用程序化生成的占位图
- 先古之民复用原版(Neow / Darv)的对话与选项,未制作独立 NPC
- 仅支持单人模式,多人联机同步未验证
